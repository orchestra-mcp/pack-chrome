# orchestra-mcp/pack-chrome

Chrome extension development skills with Manifest V3

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-chrome
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-chrome")
```
